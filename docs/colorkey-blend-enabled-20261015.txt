Implementation
- Effective keying still requires COLORKEYENABLE and an attached surface key.
  Explicit state144=1 selects transparent-black substitution before filtering.
- Draw descriptor field40 captures state144 and participates in texture-cache
  identity. Decode mode2 clears RGBA for keyed native indices (including when
  nonkey palette entries have identical RGB); truecolor retains RGB key match.
- GPU lowering disables only the implicit legacy key cutoff for this mode.
  The existing application's alpha stage, alpha test, blending and depth apply.
- Software carries this mode through the existing draw/span argument. A keyed
  sampler replaces each tap before the existing fixed-point bilinear filter.
  Explicit mode uses the general sampler for 16-bit textures, bypassing the
  unmodified SIMD fast16 filter. Wrap, mirror and edge-clamp retain their
  existing addressing. The GL border interface is unchanged.
- DDPCAPS_ALPHA plus an effective explicitly enabled key fails visibly: GPU
  reports unresolved precedence before acquiring leases, software/decode trap.
  Unkeyed alpha-palette draws are unaffected by that guard. No precedence is
  invented; old FALSE behavior is retained, not declared normative.
